# Preserve migration 008 with an operator-gated pre-008 bootstrap

## Decision

Keep published TAX-06 migration 008 byte-for-byte unchanged. Databases blocked at revision 007 use
an idempotent owner-side bootstrap that installs 008's state with collision-free environment-local
surrogates and stamps 008 only after full postcondition validation; forward revision 009 then
adopts and enforces the allocation ledger for both bootstrapped and ordinary installations.

## Context

[P2-44](../plans/2026-08-01-p244-tax06-surrogate-id-repair.md) exists because migration 008 fixes
category IDs at 11–23 and subcategory IDs at 42–108, while the measured populated snapshot already
owns category 11. A later Alembic revision cannot repair that 007 database because Alembic must run
008 before reaching it. Existing integer IDs have also been emitted to read copies, so relocating
the collision would violate identity and reference preservation.

## Alternatives considered

- Amend 008 to allocate dynamically — rejected because 008 is published and some disposable/clean
  installations have already recorded it; changing historical migration behavior makes revision
  identity dishonest.
- Renumber the existing colliding rows before 008 — rejected because the integers have local and
  cross-service references and the repair must preserve them.
- Add only revision 009 — rejected because it is unreachable from the failing 007 state.
- Replace the Alembic branch after 007 — rejected because merging the old and replacement branches
  still attempts both migrations, while abandoning the old head strands databases already at 008.

## Consequences

The normal path remains ordinary Alembic, and 009 provides a single forward head. The exceptional
007 snapshot needs an explicit stopped-publisher operator step and stronger stamping checks. Target
integer surrogates may differ by environment; pinned UUIDv7 and semantic keys remain the canonical
cross-service identity. The bootstrap must track 008 closely, so tests compare its postconditions
against a clean 008 installation and fail closed on drift.
